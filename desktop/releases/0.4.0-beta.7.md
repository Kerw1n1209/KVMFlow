混屏模式和局域网同步第七个测试版。

新的初始化流程：
- 不再区分主机和副机。两台电脑走同样的三步：本机检测、连接另一台电脑、测试切换。
- 先初始化的电脑进入等待；在第二台电脑上打开 KVMFlow 后，会自动找到并直接配对，不再需要核对配对码。局域网里有多台电脑在等待时，列出来让你选择。
- USB 切换器由两台电脑对齐识别：第一台记录按下切换器时离开的设备，第二台确认这些设备已经接到本机后才采用；对不上时在“测试切换”这一步重新识别。
- 找不到另一台电脑时，可以按 IP 地址连接。
- 去掉“记录本机输入”这一步，显示器输入值仍可在设置中查看。

已知限制：
- 新流程尚未在两台真机上完整验证。
- Windows 显示器断开尚未真机验证，默认关闭。
