局域网配对和全新界面。

新增：
- 局域网配对：两台电脑走同样的初始化步骤，自动发现并配对，之后共用一份配置。搜不到时可以按 IP 地址连接。
- 应用内反馈：在诊断页或托盘菜单中选择“反馈…”，发送前可以预览内容。
- 接收测试版：在设置中打开后，可以通过应用内更新收到测试版本。

改进：
- 全新的界面和应用图标。
- 界面字体随应用打包，不再依赖系统字体。
- 从旧版本升级时，配置会自动迁移。

已知限制：
- 这个版本带有尚未完成的混屏模式，不是正式功能，不建议使用。0.4.1 已移除入口。
- Windows 显示器断开尚未真机验证，默认关闭。

安装包支持 macOS Apple Silicon 和 Windows x64。
