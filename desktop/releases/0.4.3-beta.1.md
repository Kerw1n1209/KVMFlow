不用 USB 切换器，也能用快捷键在两台电脑之间切换键鼠和显示器。

这是测试版，局域网键鼠共享还没有经过完整的真机测试。遇到问题可以在「诊断」页面反馈。

变更：
- 新增局域网快捷键模式：按快捷键，键鼠和显示器一起切到另一台电脑。键鼠共享基于开源项目 Deskflow。
- 初始化时可以选择用 USB 切换器还是快捷键。
- 新增切换提示，键鼠到达时屏幕上会短暂显示。
- 设置里可以改快捷键、同步剪贴板、映射 Command 和 Ctrl、反转滚轮，还可以保持两台电脑不休眠。
- 菜单栏新增「共享键鼠」开关和「收回键鼠」，菜单栏图标也换成了单色。
- 调整了文案、侧边栏和设置页布局。

注意：
- 两台电脑都要升级到这个版本。
- 目前只支持两台电脑。
- macOS 需要允许「辅助功能」和「输入监控」。从这个版本起 macOS 版换了固定的签名，之后更新不用重新授权。

安装包支持 macOS Apple Silicon 和 Windows x64。
